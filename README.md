that makes online shopping convenient.

No framework or build tools are required.

ayajbuy-website/

## Local Development

Simply open index.html in your browser.

No installation or dependencies are required.

## Deployment on Vercel

1. Push this repository to GitHub.
2. Sign in to Vercel.
3. Import the ayajbuy-website repository.
4. Select Other as the framework preset.
5. Leave the build command empty.
6. Set the output directory to .
7. Click Deploy.

## Custom Domain

Add these domains in Vercel:

- ayajbuy.com
- www.ayajbuy.com

Configure the DNS records using the values
provided by Vercel in your Namecheap account.

## Before Publishing

Replace:

REPLACE-WITH-YOUR-EMAIL

with the actual AyajBuy business support email.

Review all website content and ensure the business
information is accurate before publishing.
